About the app

Jarvis Personal is a Windows desktop assistant maintained for its owner's personal use. It accepts voice and typed questions, uses a local language model, and helps retrieve personal notes and everyday information.

Optional Google connection

With the account owner's permission, Jarvis can look up Gmail message information, calendar events, and contacts. Its current Google integration is read-only: it does not send email, change events, or edit contacts.

Google sign-in and consent happen through Google during the desktop app's connection setup.

About this website

This is an informational website. It does not run Jarvis, offer a sign-in form, or connect visitors to Google services. The desktop app and its connection credentials are not hosted here.

This app is for personal use and is not offered as a public service.
