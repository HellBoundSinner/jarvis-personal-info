Jarvis Personal

Privacy policy

Last updated: October 5, 2026

Purpose and scope

Jarvis Personal is a desktop assistant maintained for its owner's personal use. This policy describes its current read-only Google integration and this informational website.

Google information accessed

Only accounts explicitly connected by the owner are accessed. The app requests permission to read Gmail messages and settings, read calendar events, and read contacts. Current commands retrieve email metadata such as senders and subjects, calendar event details, and contact names, email addresses, and phone numbers to answer the owner's requests.

The app does not request permission to send or delete email, modify calendar events, or edit contacts.

How information is used

Google information is used to answer the owner's questions through the local desktop interface and spoken responses. The current Google command handler formats these responses locally; it does not send those results to a cloud language model or use them to train a general-purpose AI model.

Google user data is not sold, used for advertising, or shared with other people by this integration. Requests and authentication are sent to Google to provide the requested services.

Jarvis Personal's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Connection credentials are stored on the owner's Windows computer using Windows data protection. The public website contains no account credentials or Google account data.

Google responses are not automatically added to Jarvis's memory vault or model conversation history by the Google command handler. Questions and spoken responses may appear in local session logs. Those logs remain until the owner deletes them; this policy does not promise automatic log deletion. Information the owner manually copies or saves is under the owner's control.

Control and deletion

The owner can revoke Jarvis Personal's access in their Google Account connections settings. Revoking access stops future authorized requests but does not erase existing local logs. Local connection storage and logs can be deleted from the owner's computer. Reconnecting requires the owner's consent through Google.

This website

These pages contain no login forms, analytics scripts, or embedded Google account information. The hosting provider, GitHub Pages, may process standard request information such as IP addresses to deliver and secure the website, as described in GitHub's privacy statement.

Questions and changes

Use the developer support email displayed on the app's Google consent screen for privacy questions. If the app's handling of Google information changes, this policy should be updated before those changes are used.
